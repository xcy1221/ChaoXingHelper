# ChaoXingVideoHelper

学习通视频失焦保护与自动顺序连播的 Tampermonkey 脚本，当前版本 v0.3.0。

## 使用

1. 在 Tampermonkey 中新建脚本，粘贴 `chaoxing-helper.user.js` 全文并保存；更新时覆盖旧脚本。
2. 刷新课程页，失焦保护自动启用。手动播放一次后点“开始连播”。
3. 同页多个视频依次播放；本页任务点确认完成后切换本节下一页签，最后进入下一视频章节。
4. 每次切换先暂停前一个视频。整页刷新保留连播状态；点“停止”终止连播并暂停视频。

仅保留一个正在学习的课程标签页。任务点视频结束后等待平台确认，90 秒未确认则停止；无任务点的视频按播放结束切换。人工交互需自行完成，测验不自动作答。

禁用脚本并刷新页面即可恢复原行为。学习进度以平台记录为准，真实课程适配取决于平台页面结构；模拟测试不代表服务端验证通过。

## 验证

需要 Node.js，无第三方依赖。在仓库根目录运行：

```sh
node --check chaoxing-helper.user.js
node tests/smoke.cjs
node tests/multi-video.cjs
```

覆盖失焦事件、同页多视频、二/三页签、延迟加载、停止和刷新续播。

## 数据

脚本不包含固定账号、课程标识、Cookie 或密钥，不修改观看进度字段。连播开关仅保存于当前标签页的 sessionStorage。截图和本地调试文件不纳入仓库。
